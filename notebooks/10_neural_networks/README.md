## What this module is for

Neural networks, built up from one neuron. Backpropagation is implemented in NumPy before PyTorch appears, so the framework is a faster hand rather than a black box.

Core chapters run on a laptop CPU. Anything needing a GPU is marked optional and says so.

## Before you start

- **Needs:** 03-07, 03-08, 06-02
- **Unlocks:** 11-03, 11-04, 12-03
- **If you are short of time:** **10-01** to **10-05** are the mechanism. 10-09 onwards are intuition chapters that can be read without the earlier code if you are short of time - but they will mean less.
