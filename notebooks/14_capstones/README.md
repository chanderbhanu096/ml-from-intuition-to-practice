## What this module is for

Capstones. Each one requires decisions and written justification rather than a recipe, and each is longer than a normal chapter.

The final project starts one step before every other project in this course: deciding whether machine learning is appropriate at all.

## Before you start

- **Needs:** 06-12, 07-07, 08-08, 09-09, 11-05, 13-08
- **Unlocks:** the end of the course
- **If you are short of time:** Nothing - but do them in order. 14-01 is guided and the guidance decreases from there.
