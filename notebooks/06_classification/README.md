## What this module is for

Classification: predicting a category. Half of this module is about *metrics and thresholds* rather than models, because that is where classification projects actually fail.

Accuracy is dismantled in 06-04, rebuilt as precision and recall in 06-05, turned into a cost decision in 06-07, and only then do the model families arrive.
