## What this module is for

Data literacy. Most modelling disasters are data misunderstandings that were visible in the first hour, and this module is that hour.

The order is deliberate: what a row is, where it came from, who is missing, what is broken, what is merely surprising, what appears when you look at two columns at once, and how to show it honestly. Only then does a real dataset arrive.
