## What this module is for

Responsible and production machine learning. Fairness, privacy, documentation, packaging, testing, deployment and monitoring - the work that starts when the model is finished.

The recurring theme is that deploying a model is the beginning of the work, not the end: the world moves, and nothing in the model notices.

## Before you start

- **Needs:** 04-07, 04-08, 07-05, 12-02
- **Unlocks:** 14-01
- **If you are short of time:** **13-04** (packaging) and **13-08** (monitoring) are the two that decide whether a model survives contact with production.

true answer in advance is the only way to check whether a method finds it.
