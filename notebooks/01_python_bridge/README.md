## What this module is for

The optional bridge. Enough Python, NumPy, pandas and matplotlib that the rest of the course is one problem at a time rather than two - a new idea *and* a syntax fight.

Every chapter here ends with a failure lab, because the mistakes these tools invite - a wrong axis, a chained assignment, a join that multiplies rows, an unseeded split - are exactly the mistakes that later produce a model that looks fine and is not.

## Before you start

- **Needs:** 00-01
- **Unlocks:** the end of the course
- **If you are short of time:** Take the diagnostic in **01-01** first. Score 9 or more and skip the module entirely; 6 to 8 and read only the chapters your failures point to.
